kochi

a proactive agent for iPhone.
quiet most of the time.

about

this is not a productivity tool.
you will not be able to ask it
what's on your calendar.

kochi runs on iOS 26+ and talks to an OpenClaw agent. you type, it answers, the screen is quiet.

the signal

once a day, between 09:00 and 21:00 local, a small file is fetched from claudio.la/chaos.json. the file is signed with our private Ed25519 key. your phone holds the public half, pinned at install.

// we chose the key.
// we did not choose the hour.

known anomalies

  • the file is not always fetched at the same hour each day.
  • this is the feature.
  • after 23:00, the agent is sometimes less professional. we are aware.
