1. The thread is the journey

Keep Dodo's text chat as the master container — but make it mean something in Infinity Chat. Every event in your learning journey becomes a message in one scrolling thread: the voice chats you had, the fixes Polly found, the cards she made, the Italian you typed, and the things you asked her to do. Nothing lives in a sheet on top of a chat window anymore; the chat window is the place.

The one rule
If it happened in Infinity Chat, it's a message. A voice conversation lands in the thread as a card. Its clean-up lands as fix cards. A quiz pass lands as a "Mastered" ribbon on that card. Typing Italian is practice; typing English is instructing Polly. You scroll up to see how far you've come.

The thread

This is the whole mode on one screen. Compare it with today's chat window (the one where Polly says "there are no titled sources, notes, or documents on file"): same container, but now the container knows what it holds.

What changes, concretely

In the app (TopicDetailView)

  • Kill the pinned bar + sheet. InfinityChatBar and the InfinityHomeView sheet go away. Conversations render inline as timeline cards (chatCard from InfinityView.swift becomes a message type).
  • Message kinds. The thread gets three non-text message kinds: conversation (a voice chat + its status), fixes (the clean-up result), deck (cards the agent made). All three are already server objects; they just need a place in the message list ordered by created_at.
  • Composer. Mic first (opens the same VoiceSessionView), text second, placeholder in the studied language. Chip row comes back for Infinity: Parla · Cards · Quiz · Polly…
  • Header. Stars → "n chats · n mastered · level". The "O✦" model button stays in the kebab.
  • After hanging up, the app posts the card immediately and calls clean-up in the background; the card animates from "reading it back" to its fixes. No tap needed.

On the server (src/lib/polly)

  • Two lanes in one chat route. chat.ts classifies the turn: studied-language text → the conversation prompt (reply in Italian at the learner's level, at most one gentle fix, folded); English or "Polly, …" → the agent (agent.ts, terse). The existing router already has continue_chat / chitchat; this adds the language signal.
  • Infinity tools for the agent: list_chats, rename_chat, cards_from_chats(topic, n, focus), clean_up_chat. Today the agent has add_flash_cards but no idea what an Infinity chat is — that's why it answered "no titled sources".
  • Typed practice is also a chat. When a typed exchange goes quiet (or you tap "Clean up"), it becomes an InfinityChat row like a voice session, so it gets the same fixes / vocab / grammar / quiz. One pipeline, two inputs.
  • Reply length for the agent lane: ≤ 2 sentences + a card. Enforce in the prompt, not by hoping.

Where it's strong, where it's weak

Strong

  • Smallest change to the codebase: Dodo's chat window survives, Infinity is one topic kind with richer messages.
  • The journey is visible. Scrolling up through last week's fixes is itself review; today that history is gone once the sheet closes.
  • Text practice is a first-class modality, in the same place, with no mode switch — the language you type is the switch.
  • Agent admin stays exactly where you like it, only now it works (tools + terseness).
  • Same pattern fixes the path lesson's empty chat (screen 20-path-lesson): the lesson card and its three steps are just the first messages.

Weak

  • It still looks like a chat app. The promise "Duolingo, next gen" is a product that doesn't look like ChatGPT; this one does, on its home screen.
  • The composer has to serve three jobs (speak, practice, instruct). Language detection will misfire sometimes ("ciao Polly, make cards…") and a wrong lane is confusing.
  • A long thread gets heavy: cards, fixes and chit-chat interleaved. Needs a "jump to your chats" affordance after a few weeks.
  • The cards inside a thread are a custom message renderer per kind — more SwiftUI than it sounds.

Open questions

  • Does typed Italian get cleaned up per message (fold under Polly's reply, as drawn) or per session (batch, like voice)? Drawn: per message, light; a session-level clean-up when you ask.
  • Should the conversation card open a detail page (the transcript, all fixes, all words) or expand in place? Drawn: expand in place; a detail page is the Direction 2 answer.
  • Do Peck and the daily iMessage card draw from all Infinity chats by default, or only mastered ones? (Same question in both directions.)
