2b. Text as a peer to voice

Same skeleton as Direction 2 — the study sheet becomes the screen, a chat is a page, the radio and the clean-up walk stay — but text chat is no longer a drawer you summon from a corner. It's the smaller button under the voice button, wherever the voice button appears. Two ways to have the same conversation; voice is the big one.

What changed from 2
One button pair, everywhere; one text thread, no modes. Every place that offers Talk offers Type right under it, at two-thirds the weight. Tapping Type opens a full-screen text chat about the same thing — not a half sheet, not a segmented control. Practice and instructions live in that one thread: Italian is practice, English is "do this". The 💬 header button and the Scrivi / Chiedi a Polly switch are gone.

Infinity Chat

Three screens: the home, the text chat you get from "type instead", and a chat's page. The pair appears on the home and at the bottom of every chat page as Continue.

Rules that make it hold together

  • The pair is one component (TalkPair(context:)): a full-width accent button and a text-link line beneath it. Never two equal buttons, never a segmented control. If a screen can't fit the pair, it gets the voice button alone and typing is in its "…".
  • The text chat is one screen (TextChatView(context:)), full-screen cover, used by every mode. Header: ✕, title + "⌨ typing", a mic that hands off to the radio. Footer: composer + "Finish & clean up".
  • No modes in the thread. Studied-language text → practice (reply in Italian at level, ≤1 folded fix). English → the agent answers (question → answer, instruction → do it + card), then Polly resumes the Italian thread with her last question. "Polly, …" forces the agent lane when detection would be ambiguous.
  • Typed and spoken chats are the same object. An InfinityChat (or a topic chat) carries an input: voice | text | mixed mark and otherwise nothing differs — clean-up, words, grammar, quiz, mastery, Peck, the daily card.
  • Handing off keeps the conversation. Text → mic: the radio opens with the typed transcript as context and Polly continues out loud. Voice → keyboard (the existing button on the radio) → this text screen, with the spoken transcript above.

Open questions

  • Does a typed chat count toward the streak and the "spoke ≥ 3 turns" rule that marks a lesson's Talk step? Drawn: yes for the streak; the Talk step stays voice-only (it's a speaking step).
  • Should the "type instead" line become a real button once someone has typed a few times (the pair adapts to the person)? Cheap to do; worth an A/B later, not now.
  • Without a global 💬, where does "make me 20 cards" go from the Topics list? Drawn: the Topics FAB "+" gets "Ask Polly" as its second item, opening the text chat with no context.
