## The one fact to remember
Every fellow → year → study is in CASBS's public data file:
https://casbs.stanford.edu/sites/default/files/2026-03/fellowshipdata.txt
It's JSON; each row is `[photo, name, role, year, institution, INST, discipline, STUDY#, profile, lastname]` — the **8th field is the study number**. Download + parse with python3 to look up any fellow's room or list every ghost in a study.
