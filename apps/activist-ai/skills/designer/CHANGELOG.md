# designer (was design-pass)

One line per change: the version, the date, what failed (the failure label, if a run showed it), what changed, which evals moved.

- 1, 2026-11-16: first version, as `design-pass`. The know-how (`references/design.md`), a starting stylesheet (`assets/base.css`), and `look.py`: `ola-page` at 390 and 1280 px, the defects a program can find, `ola-see` when present, rounds compared by count. Evals `s7-design-report-page`, `s8-design-dashboard`.
- 2, 2026-11-17: renamed `designer` and made a designer, not only a fix-up loop: stages loaded one file at a time (brief, idea, type, color, directions, components, polish, slop and plain, honest, hand-off); six bundled OFL font families (`fonts.py`), four type scales, a tonal palette from one hue with its contrast checked (`palette.py`), directions compared side by side (`sheet.py`), recipes in plain HTML and CSS (`assets/components.html`). `look.py` keeps design-pass's checks and adds the decorated, bare, order (squint) and usable groups from `ola-page`'s new taste measurements, and one `ola-see` look at laptop, phone and a blurred view. Evals `u1` to `u5` added.
- 3, 2026-11-17: on Nemotron 3.5 Super VL the full process ran into the 500,000-token cap in 6 of 21 runs (u1 seed 3, u3 seeds 1 and 3, u4 all three), failing pages it had nearly finished (`token_limit`). Quick mode is now the default (`references/quick.md`: the know-how in one file, one look-and-fix pass); the stages are the thorough mode the person asks for. Evals u1, u3, u4 rerun in quick mode.
- 4, 2026-11-17: asked for "3 design concepts" for a personal homepage, the model ran the directions stage and handed over one page laid out the same way in three fonts and palettes, described as a poster, a document and a ledger ("just text, three different versions"). Concepts mode (`references/concepts.md`): N whole pages, each from a different named layout, titled by concept; `sheet.py` measures the laptop first screens and exits 3 with `SAME LAYOUT` when two are laid out alike; its working files are hidden so the project lists only the pages. Proved by three live runs of the same request (OLA-130).
- 5, 2026-11-17: the owner said the skill "seems to only have 'plain, clean'" and needs "gorgeous, fun, modern, colorful stuff too" (OLA-134). A second register, Bold, beside Calm (still the default), picked from the person's words (fun, colorful, gorgeous, playful, bold, modern, make it pop) or the subject (a party, festival, fundraiser, youth campaign). `references/bold.md` with recipes (inks, display type and its scale, full-bleed fields, shapes from the subject, gradients with a reason, overlap, motion under reduced motion); `palette.py --bold` (presets riso, the owner's approved palette, night-neon, candy, duotone; schemes complementary, triadic, split, analogous-clash; each ink with the text color that reads on it and what it may carry on the ground); four display faces (Anton, Bowlby One, Fraunces, Space Grotesk); three worked examples (`assets/bold-*.html`). `look.py` and `sheet.py` read the register (`<meta name="ola-register" content="bold">` or `--register bold`): in Bold, colors, gradients, rounded shapes and big type are allowed and a timid page is called out; glows, glass, emoji, placeholder text, low contrast and sideways scroll stay banned; Calm's checks are unchanged. Evals u9-block-party, u10-youth-strike, u11-garden-fundraiser added.
- 6, 2026-11-17: on Nemotron 3.5 Super VL (u9-block-party, 3 seeds, image 2.3.0-32) the model loaded the skill but never opened bold.md: no bundled fonts, no `palette.py --bold`, a generic orange-pink gradient header with glows, pill labels and rounded cards (`design_slop`, 15/19), in about 50 s. Bold is now five commands in SKILL.md itself, which the model always reads: copy the closest worked example (`assets/bold-*.html`) and its two fonts, rewrite every word, redraw the shape for this subject, `look.py`; quick.md stops at its first step for a Bold page; `look.py` flags words left from an example.
