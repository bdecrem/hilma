## Overview (moved from the root CLAUDE.md, 2026-10-22)

Where it lives: `apps/smallgpt/`. Deploy: Mac mini or this iMac (PyTorch on `mps`), nothing deployed.

Bart's learning project, started 2026-10-12: build a complete GPT at toy scale (~10M params, BPE tokenizer, TinyStories) and touch every mechanism — micrograd backprop, tokenizer, bigram, attention, pretraining, the HF conversion bridge, SFT, DPO, optional reward model + PPO, RLVR with GRPO. **`PLAN.md` lists the fourteen steps with a status each; a step is built only after Bart signs it off, one `NN-name/` folder per step with its own README.** Never build ahead of the signed-off step. Site: `src/app/smallgpt/` (ola.cx/smallgpt; `steps.ts` holds each step's status and Bart's summary). **ola.cx/smallgpt/chat** runs the models in the browser with no server: `09-sft/export_web.py` writes int8 weights + the tokenizer to `public/smallgpt/chat/` (the 92M models of step 13 go to the public Supabase Storage bucket `smallgpt` in 24 MB parts, the .json lists them), `gpt.mjs` there is the forward pass in plain JS (must match PyTorch token for token, `09-sft/check_web.mjs`; re-export after retraining). Step 10, Scale up (2026-10-17; folder `13-scale`, renumbered from 13 on 2026-10-18 because it ran before post-training; DPO is now step 12 and skipped, RLVR step 13): the 92M model was trained on 8 H100s rented from Together (Kubernetes via `tg` + `kubectl`, API key only; runbook and gotchas in `13-scale/README.md`; delete the cluster AND its storage volume after). Everything after step 9 loads models through `13-scale/model.py` `load()`. Step 11 (`11-rlhf/`, 2026-10-17): Claude-judged pairs → reward model → PPO on the mini; the chat page's `rlhf` model; each PPO run writes 350 MB checkpoints every 25 rounds, so delete `out/rlhf/*/round*.pt` after (the iMac's disk filled once)
